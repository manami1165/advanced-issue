# Agent Teams 設計書

## 追加機能の概要
- 月次レポートAPI
 - 社員ごとの月次勤務時間・出勤日数・遅刻回数を返すAPIを追加する
 - 遅刻の定義
  - 9:00を過ぎて出勤した日を遅刻として数える
- エラーチェック
 - 退勤打刻が出勤打刻より前の場合はエラーを返す

## Agent構成

| Agent名 | 役割 | 担当タスク |
|---------|------|-----------|
| Backend Agent |APIを作る|月次レポートAPIを追加する。退勤が出勤より前の場合、エラー(400)を返す|
| Frontend Agent |画面を作る|レポート画面を作成する。一覧画面にリンクを足す|
| Test Agent |テストを書く|月次レポートとエラーチェックのテストケースを書く|
| Review Agent |最終確認をする|セキュリティとコードの品質を確認する|

## タスクの依存関係
- Backend Agent →   Frontend Agent → Test Agent → Review Agent
  - 画面はAPIがないと作成できない
  - テストはできたものに対して行う
  - レビューはすべて完了してから最後に確認する

## 並列実行できるタスク
- 事前準備
 - APIで返すものを決めておく
 - APIの作成が完了していなくても画面は作成できる
 - Frontend、Test、Backendは並列実行できる


## 統合時の確認ポイント
- 修正が競合していないか
- APIが返す項目と画面の項目が一致しているか
- 実装済みの処理が壊れていないか
